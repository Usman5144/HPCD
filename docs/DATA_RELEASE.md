# HPCD Research Data Release

This release accompanies the anonymous HPCD manuscript.

## Included

- 251 frozen HJTM human-reference texts
- 333 Development machine-source instances
- Primary and Replication source documents
- Primary and Replication frozen HPCD outputs
- CoPA and DIPPER evaluation artifacts
- Fast-DetectGPT, RADAR, SurpMark, and MAGE results
- Final statistical tables and Qwen evaluator artifacts

The primary and replication results are frozen research outputs.
No experiment was regenerated for this release.

## Dataset provenance

Source material was derived from the RAID benchmark.
Refer to the original RAID dataset and its applicable license,
attribution requirements, and source-text terms.

## Integrity

Use SHA256SUMS to verify the files in this release.

## Privacy

The public CoPA run manifest has local identifying path
components replaced by anonymous placeholders. Its original,
unmodified version remains in the private research archive.

## Scope

This is a curated publication-data release, not a complete
archive of historical checkpoints, intermediate experiments,
third-party model weights, or private evaluation records.
